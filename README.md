# ⛏️ えいごクラフト 5きゅう

小2の子どもが **英検5級(2026/10/4)** に向けて単語を覚えるための、マイクラ風の単語学習アプリです。
サーバーもインストールも不要、ブラウザだけで動きます。

## 収録単語

**パス単5級の掲載順(No.1〜150)そのまま**で収録しています。パス単は出る順・重要度順に並んでいるため、
上から順に進めるだけで重要な単語から覚えられます。

配布プリントと同じ **30語ずつのチャプター**(1〜30 / 31〜60 / 61〜90 / 91〜120 / 121〜150)で選べるほか、
内部では **10語ずつの「ワールド」15個**に分かれていて、1回の学習は10語で完結します。

## おぼえかたの流れ

1. **英語だけが表示され、同時にネイティブ発音が自動再生**される(🔊ボタンで何度でも再生可)
2. カードをタップすると答えが出る — **絵(アイコン)と日本語の両方**を同時に表示
3. あわせて **英語の例文＋日本語訳**も表示。単語だけでなく文のかたまりで覚えられる
4. 10語見終わったら4択クイズへ

### 抽象語を絵でイメージする仕組み

`week` `year` `time` `people` のような絵にしにくい語には、**ブロックを並べた図解**を表示します。

- `week` → ☀️🌙🔥💧🌳🪙🪨 の7ブロック(日・月・火・水・木・金・土 = 7日で1週)
- `year` → 🎍👹🎎🌸🎏☔🎋🎆🌕🎃🍁🎄 の12ブロック(1月〜12月で1年)
- `weekend` → 7ブロックのうち土日だけが光る
- `morning`/`afternoon`/`evening`/`night` → 1日の流れの中で該当箇所が光る

曜日は日本語の曜日名(火=🔥, 水=💧, 木=🌳, 金=🪙, 土=🪨)と対応させてあるので、覚える手がかりになります。

## やる気が出る仕組み(マイクラ風)

- **⛏️ ワールド攻略**: 草原 → 森 → 砂浜 → 石 → 石炭 → 銅 → 鉄 → 金 → レッドストーン → ラピスラズリ → エメラルド → ダイヤモンド → ネザー → エンド → エンダードラゴン と、掘り進むほどレアなブロックへ
- **❤️ ハート制**: 間違えられるのは3回まで(=8/10正解でクリア)。マイクラの体力と同じ緊張感
- **🟩 ブロック / 🧰 チェスト / 💎メダル**: 正解するとブロックが飛び散り、クリアでチェスト獲得
- **⬆️ 経験値バー**: 画面上部にマイクラそっくりのXPバー。貯まるとレベルアップ
- **🏆 進捗の達成**: マイクラの「進捗の達成」風トーストがポップアップ
- **🔥 コンボ**: 連続正解でコンボ表示、5連続で実績解除
- **🔥 連続学習日数**: 毎日続けるほど伸びる
- **📕 まちがえた単語**: クイズ後にその場で復習できる

## 週次復習(忘れない仕組み)

ワールドをクリアすると**7日後に自動で「ふくしゅう」に登場**します。ホーム画面に赤いバッジで通知され、
合格するとまた7日後に再スケジュールされます。時間を空けて思い出すことで記憶に定着します。

## 試験日カウントダウン

ホーム画面に本番(2026/10/4)までの残り日数と、残りワールド数から逆算した
「1週間に何ワールド進めればいいか」の目安を自動表示します。

## 使い方

### GitHub Pages で公開する(おすすめ)

1. リポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチをこのブランチ、フォルダを `/ (root)` にして Save
3. 発行されたURLをスマホ・タブレットのホーム画面に追加すると、アプリのように使えます

### ローカルで試す

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

学習の進み具合は端末のブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで続きから遊べます。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — マイクラ風ピクセルUI(角丸なし・ベベル・ドットフォント)
- `words-data.js` — 単語データ(パス単順150語)、ワールドのテーマ、抽象語の図解定義
- `app.js` — 進捗管理・クイズ・復習スケジュール・効果音・エフェクト

## 単語を追加するとき

`words-data.js` の `WORD_LIST` に追記するだけで、10語ごとに自動でワールドが増えます。

```js
{ en: "book", ja: "ほん", emoji: "📕", ex: "I read a book.", exJa: "わたしは ほんを よみます。" },
```

絵にしにくい語には `VISUALS` に図解を足せます。

```js
week: { icons: ["☀️","🌙","🔥","💧","🌳","🪙","🪨"], hi: [0,6], label: "7日で 1しゅう" },
```
