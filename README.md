# 📘 えいご 5きゅう

小2の子どもが **英検5級(2026/10/4)** に向けて練習するための、ブラウザだけで動く学習アプリです。
サーバーもインストールも不要。GitHub Pages に置いてスマホで開くだけで使えます。

## このアプリがやること

**単語・リーディング・リスニングの3つだけ**です。

| | 中身 | 本番との対応 |
|---|---|---|
| **単語** | Ⓐ おぼえる(15語ずつ・全28範囲・424語) / Ⓑ 曜日ボックスで復習 | 全セクションの土台 |
| **リーディング** | 大もん1(語句の空所補充・15問)<br>大もん2(会話の空所補充・10問)<br>大もん3(語句の並べかえ・10問) | 筆記 大問1〜3 |
| **リスニング** | 第1部(会話の応答文選択・10問)<br>第2部(会話の内容一致選択・10問) | リスニング 第1・2部 |

### ゲーム要素は入れていません

以前はマイクラ風のアイテム収集・パック開封・XP・ブロック・チェスト・連続日数といった
仕組みが入っていましたが、**試験が近づいて「リーディングが全然できない」ことが分かった時点で
全部外しました**。残っているのは正誤の表示と進捗バーだけです。

同じ理由で、見た目もドット絵風から**素の読みやすさ優先**に作り直しています。
英文は等幅のドットフォントをやめ、読みやすいサンセリフ(Inter)で大きめに組んでいます。
リーディングが目的のアプリで英文が読みにくいのは本末転倒なので、ここは最優先にしました。

## 収録単語

**パス単5級の掲載順そのまま**で収録しています。出る順・重要度順に並んでいるため、
上から進めるだけで重要な語から覚えられます。

配布プリントと同じ番号のまま、**基本15語ずつのⒶ範囲(全28範囲・424語)**で選んで学習します。

### 320〜495番の176語は収録していません

試験までの日数が限られているため、**合格に必要な424語だけに絞りました**。
外した176語(320〜495番)は、家具・建物・職業・特定の食べ物・天気の形容詞など
(`chair` `magazine` `young` `slow` など)、5級で出ても1〜2問という語です。

`all` `any` `Mr.` `Ms.`(316〜319番)は、外した範囲の先頭にたまたま並んで
いただけで5級では普通に出るため、**この4語だけ残してあります**。
その結果21番目の範囲は301〜319番の19語とやや多めですが、4語だけの
半端な範囲を作るよりまとまりが良いのでそうしています。

一方で**496〜600番は残しています**。ここは数字(one〜twelve)・曜日・月・代名詞・
熟語(`after school` `a lot of` など)で、リスニングにも大問3の語句整序にも
直結するため、優先度はむしろ高い部類です。

**番号は配布プリントに合わせたまま**にしてあります(1〜319番 → 496〜600番と飛ぶ)。
手元のプリントと突き合わせられなくなると困るためです。

## Ⓐ→Ⓑ のしくみ(曜日別ボックス方式)

- **Ⓐ おぼえる**: 範囲を選んでカード→クイズ。正解するたびカウントが+1され、ドット(●●●)で表示
- **3回正解でⒷへ**: カウントが3に達すると、答えた日の**曜日のボックス**(月〜日)に移動し、Ⓐから外れる
- **Ⓑ ふくしゅう**: 曜日ごとのボックスを開いて復習。今日の曜日のボックスがホームで通知される
- **間違えるとⒶに逆戻り**: ボックス内で間違えるとカウントがリセットされⒶに戻る

学習した曜日ごとに復習が自然に分散されるので、特定の日に集中せず毎週思い出す機会が来ます。

### こたえかたは3つから選べる

| モード | 何をする | 向いている場面 |
|---|---|---|
| **こえで** | 子どもが声で答えて、親が ⭕❌ を押す | 親と一緒。いちばん速い |
| **4たく** | 4つの選択肢から選ぶ | ひとりでもできる |
| **かく** | 日本語をキーボードで入力する | いちばん頭を使う |

「こえで」は答えを最初から出すと子どもが見てしまうので、**「こたえを見る」を押すまで隠します**。
絵も伏せたままなので、そこから答えが割れることもありません。

## 📝 機能語は「文の穴うめ」で覚える

`at` `of` `is` `am` のような語は、**単語カードで1語だけ見せても覚えられません**。
「of = の」と暗記しても文の中で使えないからです。
そこで機能語は、単語の意味を問うのをやめて**文の穴うめで出題**します。
Ⓐの「おぼえるカード」にもこれらの語は**一切出しません**。

- **読み上げは空所を飛ばします**。答えの語まで読むと聞くだけで分かってしまうためです。
  空所の位置では代わりに短い合図音が鳴ります
- 対象は `TYPE_HARD_EN` のうち単語データに実在する**34語**。
  例文データ側は全424語のうち**407語**で穴うめが作れることを確認済み
- ある範囲がすべてこの機能語だった場合(286〜300番)は、カードを飛ばして直接クイズから始まります

### まちがい選択肢は1語ずつ手で選んである

ランダムに選ぶと「どちらでも文法的に正しい」問題ができてしまいます
(`I am ( ) school.` に `at` と `in` を並べると両方正解になる)。
そこで対象の語すべてについて、**絶対に入らない語**を3つずつ手で指定しています。

## 💬 リーディング・リスニングの問題文について

**⚠️ 著作権**: 英検の過去問題冊子には複製・漏えいの禁止が明記されています。
このアプリはGitHub Pagesで公開されるため、過去問を一字一句転記することはできません。
そのため収録している会話文は**すべて新規に書き下ろしたオリジナル**です(全99本)。
出題の「形式」(会話が何行か、選択肢がいくつか)だけを本番に合わせ、中身は独自に作成しています。

| データ | 本数 |
|---|---|
| `DAIMON1_POOL`(大もん1) | 31 |
| `DAIMON2_POOL`(大もん2) | 24 |
| `LISTEN1_POOL`(リスニング第1部) | 24 |
| `LISTEN2_POOL`(リスニング第2部) | 20 |

大もん3(語句整序)だけは単語データの例文から作れたため、**400文**がそのまま使えています。

> **リスニング第3部について**: 以前は絵文字を見てあう英文を選ぶ練習を用意していましたが、
> 絵文字だけでは状況が伝わりにくく使いものにならなかったため削除しました。

## 読み上げ(音声)について

Web Speech API を使い、端末に入っている読み上げエンジンで発音します。

- **英語**は覚える対象なのでゆっくり(rate 0.85)、**日本語訳**は意味の確認なので速め(1.35)
- 日本語は**端末内の声を優先**します。ネットワーク音声は喋る前に取りに行くぶん
  出だしが遅れ、英文のあとに間があいてしまうためです。英語は質を優先してネットワーク音声を使います
- 声の選択結果は `voiceURI` だけ覚えておき、使うときに今の一覧から引き直します
  (声のオブジェクトを持ち続けると、端末が一覧を作り直したときに無効になり無音になるため)
- 読み上げが壊れて `onend` が返ってこない端末でも、文字数から計算した保険タイマーで必ず進めます

**音が出ない場合**は端末側の読み上げエンジンが原因のことが多いです。
設定で「テキスト読み上げ」を検索し、Google テキスト読み上げが入っているか、
**英語の言語データがダウンロードされているか**を確認してください。

## 保存について

進捗は `localStorage`(キー `eigo_craft_v5`)に保存されます。端末を再起動しても消えません。
ただし**ブラウザの閲覧データ削除・シークレットタブ・別ブラウザ**では失われる/見えないので、
**いつも同じブラウザで開く**ようにしてください。

単語の `id` は配列の位置ではなく**パス単の番号そのもの**を使っています。
位置にすると単語を足し引きするたびに全部ずれて、保存済みの記録が別の単語に付いてしまうためです。
過去バージョン(v3: 600語 / v4: 420語)の記録は、起動時に番号を手がかりに自動で移行します。

## ファイル構成

- `index.html` — 画面の骨組み
- `style.css` — 見た目(読みやすさ優先のデザイン)
- `app.js` — 全ロジック
- `words-data.js` — 単語データ(パス単順424語)、Ⓐ範囲、曜日ボックス、SVG図解、
  穴うめ対象語(`TYPE_HARD_EN`)とまちがい選択肢(`CLOZE_DISTRACTORS`)、答えの言いかえ表(`JA_ALT`)
- `dialogue-data.js` — 大もん1・大もん2・リスニング第1部/第2部のオリジナル会話文(99本)
