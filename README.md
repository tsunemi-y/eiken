# 📘 えいご 5きゅう

小2の子どもが **英検5級(2026/10/4)** に向けて練習するための、ブラウザだけで動く学習アプリです。
サーバーもインストールも不要。GitHub Pages に置いてスマホで開くだけで使えます。

## このアプリがやること

**最重要の155語を、1まいのカードで「読む」「聞く」「覚えたと自分で決める」だけ**のアプリです。

- カードには**英語の語(または文)がそのまま表示**されます → これが「読む」
- 🔊ボタンを押すと発音します → これが「聞く」
- **「✅ これは おぼえた」を押した語だけ**が、おぼえたことになります

読む・聞くを別モードに分けていません。英語を見せたうえで発音ボタンを出せば、
その1枚で両方まかなえるためです。正誤を判定するテスト(クイズ・4択)もありません。
子ども自身が「もう分かる」と判断してボタンを押したときだけ記録が進みます。

### 入れていないもの

本番が近づき、子どもが**文を読むところまで届いていない**ことが分かったため、
まず単語を「読んでわかる」「聞いてわかる」状態にすることに絞りました。
その後さらに、リーディング/リスニングの分離も、正誤判定も、進捗の自動計算も
複雑さの元だったため取り除きました。

- 大もん1〜3・リスニング第1部/第2部の練習、会話文のオリジナルデータは外しました
- リーディング/リスニングの画面わけ、答えかたの切りかえ(こえで/4たく/かく)、
  多肢選択クイズは外しました。**カード+「覚えた」ボタンだけ**です
- **Ⓐ(単語練習)/Ⓑ(曜日ボックス復習)という区分も外しました**。
  「3回連続正解で自動的にボックスへ」のような自動判定はせず、
  **「覚えた」ボタンを押した語だけ**が、おぼえた語として記録されます
- ゲーム要素(アイテム・パック・XPなど)も入れていません。
  残っているのは進捗バーだけです

見た目は**素の読みやすさ優先**です。英文は等幅のドットフォントをやめ、
読みやすいサンセリフ(Inter)で大きめに組んでいます。

### どう選んだか

5級はいちばん易しい級なので**ほぼ全部が頻出**で、どこを削っても何かは失います。
そのうえで次の方針で選びました。

- パス単は品詞・テーマごとに並んでいる(名詞→動詞→形容詞→機能語→数字→代名詞→熟語)ので、
  「前から◯語」で切ると**名詞だけが残って動詞が1つも入らない**。そのため分類ごとに選んでいる
- 文を読むのに欠かせない**代名詞・疑問詞・be動詞・基本動詞・前置詞**を優先
- 同じ語が2回載っているもの(`one` `you` `his` `her` `it`)は1つだけ
- 目的格(`him` `us` `them`)、所有代名詞(`mine` など)、4番目以降の序数、`a` `the` `of` は外した
- 名詞と形容詞は、学校・家族・食事・時間など5級の基本場面に出るものだけ

### 番号はパス単のまま・元に戻せる

**番号は配布プリントと同じ**です(範囲の見出しも「1〜45ばん」のようにプリントの番号)。
範囲は並び順のまま、ほぼ15語ずつ(16語×5・15語×5)に均等に分けています。

データ自体は消しておらず、`words-data.js` の `CORE_NOS` で絞っているだけなので、
番号を足せばすぐ戻せます。単語の `id` はパス単の番号そのものなので、絞っても
**保存済みの記録はずれません**。絞る前に覚えた語の記録も消さずに残してあり、
戻せばそのまま復活します(「おぼえた ◯/155ご」には範囲内の語だけを数えます)。

## おぼえかたの流れ

1. ホームの「たんごを おぼえる」→ 範囲(15語前後)を選ぶ
2. 単語一覧が出る。すでに知っている語は「覚えた」ボタンでその場ですぐ済ませられる
3. 「カードで おぼえる」でカード1枚ずつめくる。表は英語(と🔊ボタン)だけ、
   タップすると裏に絵・意味・例文が出る
4. その場で分かる語は「✅ これは おぼえた」。まだの語は「つぎ →」で先送り
5. 「覚えた」を押した語はその場で今回のカードの列から外れ、二度と同じ範囲で
   めくり直す必要がなくなる。範囲を全部おぼえ終えると自動でお知らせが出る

**カードの順番も、単語一覧の並びも、開くたびにシャッフルされます**。
パス単の並び順(father の次は必ず mother、Sunday の次は Monday、など)で
覚えてしまうと、単語だけを見て答えられているのか確認できないためです。
一覧は開いたときに1回だけ混ぜ、「覚えた」を押しても並びは変わりません
(押すたびに並びが変わると探しにくいため)。No. はパス単の番号のまま表示します。

## 📝 機能語はカードでも「文の穴うめ」で見せる

`at` `of` `is` `am` のような語は、**単語1つだけ見せても覚えられません**。
「of = の」と暗記しても文の中で使えないからです。
そこでこれらの語だけは、カードの表を単語そのものではなく**例文を空所つきで**表示します
(`I ( ) happy.` のように)。🔊ボタンも空所を飛ばして読み上げるので、
音を聞いても答えが分かってしまうことはありません。
裏に返すと、空所に答えが入った文(答えの語だけ緑でハイライト)と日本語訳が出ます。

- 対象は `TYPE_HARD_EN` のうち単語データに実在する語
- 例文データ側は全155語のうち**154語**で穴うめ表示が作れることを確認済み

## 読み上げ(音声)について

Web Speech API を使い、端末に入っている読み上げエンジンで発音します。

- **英語**は覚える対象なのでゆっくり(rate 0.85)、**日本語訳**は意味の確認なので速め(1.35)
- 日本語は**端末内の声を優先**します。ネットワーク音声は喋る前に取りに行くぶん
  出だしが遅れ、英文のあとに間があいてしまうためです。英語は質を優先してネットワーク音声を使います
- 声の選択結果は `voiceURI` だけ覚えておき、使うときに今の一覧から引き直します
  (声のオブジェクトを持ち続けると、端末が一覧を作り直したときに無効になり無音になるため)
- 読み上げが壊れて `onend` が返ってこない端末でも、文字数から計算した保険タイマーで必ず進めます

**音が出ない場合**は端末側の読み上げエンジンが原因のことが多いです。
設定で「テキスト読み上げ」を検索し、Google テキスト読み上げが入っているか、
**英語の言語データがダウンロードされているか**を確認してください。

## 保存について

進捗は `localStorage`(キー `eigo_craft_v6`)に保存されます。端末を再起動しても消えません。
ただし**ブラウザの閲覧データ削除・シークレットタブ・別ブラウザ**では失われる/見えないので、
**いつも同じブラウザで開く**ようにしてください。

単語の `id` は配列の位置ではなく**パス単の番号そのもの**を使っています。
位置にすると単語を足し引きするたびに全部ずれて、保存済みの記録が別の単語に付いてしまうためです。

以前のⒶ/Ⓑ方式(v5)の記録は起動時に自動で移行します。**Ⓑボックスまで卒業していた語
(3回正解ずみ)だけ**を「覚えた」として引き継ぎ、Ⓐで途中(1〜2回正解)だった語は
引き継ぎません。「覚えたボタンを押した語だけを記録する」という今のルールに
合わせるためで、旧データ(`eigo_craft_v5`)はひかえとしてそのまま残っています。

## ファイル構成

- `index.html` — 画面の骨組み
- `style.css` — 見た目(読みやすさ優先のデザイン)
- `app.js` — 全ロジック
- `words-data.js` — 単語データ(パス単順。`CORE_NOS` で155語に絞り込み)、範囲の定義、SVG図解、
  穴うめ対象語(`TYPE_HARD_EN`)と穴うめ表示ロジック(`clozeParts`)
