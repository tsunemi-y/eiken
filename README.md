# ⛏️ えいごクラフト 5きゅう

小2の子どもが **英検5級(2026/10/4)** に向けて単語を覚えるための、マイクラ風の単語学習アプリです。
サーバーもインストールも不要、ブラウザだけで動きます。

## 収録単語

**パス単5級の掲載順(No.1〜600)そのまま**で収録しています。パス単は出る順・重要度順に並んでいるため、
上から順に進めるだけで重要な単語から覚えられます。単語だけでなく、後半には代名詞(I/my/me/mine…)や
熟語(get up, look at ~, a lot of ~ など)も含みます。

配布プリントと同じ番号のまま、**15語ずつのⒶ範囲(全40範囲)**で選んで学習します。

## おぼえかたの流れ

1. **英語だけが表示され、同時にネイティブ発音が自動再生**される(🔊ボタンで何度でも再生可)
2. カードをタップすると答えが出る — **絵(アイコン)と日本語の両方**を同時に表示。
   このとき**例文が自動で英語→日本語の順に読み上げ**られ、
   **日本語を読み終わるまで「つぎ」「まえ」「クイズへ」が押せません**
   (子どもが面倒がって音声を飛ばしてしまうため)。
   読み上げ中は「🔊 にほんごの さいごまで きいてね…」と点滅表示されます。
   読み上げが壊れて `onend` が返ってこない端末でも、文字数から計算した保険タイマーで
   必ずロックが解けるので固まりません
3. あわせて **英語の例文＋日本語訳**も表示。単語だけでなく文のかたまりで覚えられる。
   例文をタップすると**英語→日本語の順で連続して読み上げ**ます。
   このとき2つの読み上げを**先にまとめて予約**しておくので、英語を読んでいる間に日本語の準備が進み、
   英語が終わってから日本語が始まるまでの間があきません
   (声の選択結果もキャッシュしています。`getVoices()` は端末によっては重く、
   読み上げのたびに舐め直すとそれ自体が間の原因になるため)
4. 全部見終わったら4択クイズへ

### 絵にしにくい語を手描きSVGでイメージする仕組み

`week` `year` `time` のような絵文字だけでは伝わりにくい語には、**専用に手描きしたSVG図解**を表示します(画像ファイル不要、コードで直接描画)。

**時間・こよみ系**
- `week`/`weekend` → 曜日7マスのストリップ(該当日がハイライト)。曜日は日本語の曜日名と色を対応(火=🔥赤, 水=💧青, 木=🌳緑, 金=🪙金, 土=🪨灰)
- `month` → カレンダーのマス目
- `year` → 12ヶ月を季節の色(冬=水色/春=ピンク/夏=黄/秋=オレンジ)で円状に配置
- `day`/`morning`/`afternoon`/`evening`/`night` → 空の色と太陽・月の位置で時間帯を表現
- `hour`/`time`/`noon` → 時計の針とパイ型ハイライト
- `date`/`today`/`tomorrow` → 3マスのカレンダーストリップで「まえ・きょう・つぎ」を表現

**文法・つなぎ言葉系**(151〜300番で新登場)
- `always`/`usually`/`often`/`sometimes` → 4マスのメーターで頻度を表現(塗りつぶし数で「どのくらいよくするか」)
- `in`/`on`/`under`/`near`/`with` → 箱と丸で位置関係を表現(ザ・定番のESL前置詞図解)
- `from` → 起点から伸びる矢印
- `about` → 点線の円+「≈」で「だいたい」を表現
- `before`/`after` → タイムライン上でハイライトする位置
- `and`/`or`/`but` → 2つの図形の重なり・二択・対比する感情アイコンで論理関係を表現

**疑問詞・数量詞系**(301〜450番で新登場)
- `what`/`who`/`when`/`where`/`why`/`how`/`which`/`whose` → 大きな「?」+ たずねる対象のアイコン(what=荷物, who=人, when=時計, where=ピン, why=電球, how=工具, which=矢印, whose=手)
- `all`/`every`/`many`/`some`/`any` → 6つの丸のうち塗りつぶした数で数量を表現(all/every=6/6, many=4/6, some=2/6, any=点線で未指定)

- 合格ラインを全部終えていればボーナス範囲を案内し、全部終わったら消えます

- 上部に `📅 きょうは 2はんい / 27ご れんしゅうした ・ つづきは 46〜60ばん`

  (両方あてはまる範囲は「📅 きょう やった ・ つづきは ここ」)

## 📝 機能語は「文の穴うめ」で覚える(英検5級 大問1と同じ形)

`at` `of` `is` `am` のような語は、**単語カードで1語だけ見せても覚えられません**。
「of = の」と暗記しても文の中で使えないからです。
そして英検5級の**大問1はまさに「短文の語句空所補充」**——文の空所に入る語を4択で選ぶ形式です。
そこで機能語は、単語の意味を問うのをやめて**文の穴うめで出題**するようにしました。

```
        ( ) に 入るのは どれ?

     This is a picture (   ) my dog.
        これは わたしの いぬの しゃしんです。

              🔊 きく

        [ to ]          [ of ]
        [ at ]          [ in ]
```

- **読み上げは空所を飛ばします**。答えの語まで読んでしまうと聞くだけで正解が分かり、問題として成立しないためです。
  空所の位置では代わりに短い「ポン」という合図音が鳴り、画面の `(  )` と音が対応します
  (`( ) you like dogs?` のように空所が文頭にある場合も、先頭で正しく空けます)
- 答えると**空所に正解が入って表示**され、続けて**英文→日本語訳の順に読み上げ**ます(リスニング対策も兼ねる)。
  🔊ボタンも、答える前は空所を飛ばした読み上げ、答えた後は文まるごとの読み上げに切り替わります
- 対象は `TYPE_HARD_EN` の**33語**(前置詞・接続詞・be動詞・冠詞など)。
  例文データ側は全600語のうち**403語**で穴うめが作れることを確認済み
- Ⓐのおぼえるカードでも、これらの語は例文中の該当語を**金色でハイライト**して「文の中で覚える」ことを促します

### まちがい選択肢は1語ずつ手で選んである

ランダムに選ぶと「どちらでも文法的に正しい」問題ができてしまいます
(`I am ( ) school.` に `at` と `in` を並べると両方正解になる)。
そこで33語すべてについて、**絶対に入らない語**を3つずつ手で指定しています。

```js
at:  ["to", "from", "of"],     // I am ( ) school.
in:  ["on", "under", "near"],  // The cat is ( ) the box. → 日本語訳「なかに」で確定
and: ["or", "but", "so"],      // I like dogs ( ) cats.   → 日本語訳「いぬと ねこ」で確定
```

`in / on / under` のように文法的にはどれも通る場合は、**日本語訳を見せることで正解を1つに確定**させています。

## 🧩 ごじゅんれんしゅう(本番の大もん3「語句整序」の力だめし)

本番の大問3は、あたえられた4つの語を並べかえて文を作る問題。単語の意味は全部わかっている前提で、
**文の組み立て(語順)そのものの力**を問います。これまで一切対策していなかったので追加しました。

```
        この いみに なるように ならべよう

        これは あなたへの プレゼントです。

        [   ] [   ] [   ] [   ] [   ]  .

   [ is ] [ a ] [ you ] [ This ] [ present ] [ for ]
```

- 例文をまるごとタイルにして、日本語の意味を見ながらタップで英文を組み立てる練習です
  (本番は4語から2択を選ぶ形式ですが、練習では文の組み立て感覚そのものを鍛える形にしています)
- 単語データ600語のうち、**398文がそのまま使えました**(3〜8語で記号がきれいな文)。新規データ不要
- タップしたタイルは押し直すと取り消せる、🔁やりなおすで全部リセットできる
- 間違えた位置は赤、合っていた位置は緑で表示。答えた後は英語→日本語の順で読み上げて確認します
- Ⓐ・Ⓑの記録には影響しない、語順感覚だけの練習です

## 📝 大もん1 れんしゅう(単独モード・過去問レベルの文脈問題)

最初のバージョンは単語帳の例文(「I have a pen.」のような単文)をそのまま穴埋めにしていて、
本番より簡単すぎました。実際の大問1は

> A: What do you do in your free time, John?
> B: I read a ( ) every day.
> 1 music 2 paint 3 newspaper 4 lunch

のように、**会話や2文の文脈を読んで初めて答えが決まる**問題です(`newspaper`単体の意味を
知っているだけでなく、「読む」の目的語として自然なものを文脈から選ぶ必要がある)。
そこでこのモードは、`dialogue-data.js` の `DAIMON1_POOL`(オリジナルで書いた**31問**)に
差し替え、本番と同じ「1〜2行の会話 or 短い文脈 + 単語1つの穴埋め + 同じ品詞の4択」という
構造で出題するようにしました。まちがい選択肢も1問ずつ手で選んであり、単語を知っているだけ
では解けず文脈の理解が必要です。

ホームから、この形式で**15問連続**の練習ができます。

- 会話文はそのまま画面に表示され(読む問題のため)、🔊ボタンで発音も確認できます
  (読み上げは穴の部分を飛ばし、答えを教えてしまわないようにしています)
- **やさしい ⇄ ほんばん** をボタン右のタグで切り替え
  - やさしい … 日本語訳を見せる(意味が分かった上で選ぶ)
  - ほんばん … 日本語訳を隠す(本当の試験と同じ条件)。切り替えは出題中でも即座に反映されます
- 正答率6割(英検5級の合格ライン目安)を超えるとその場でほめます
- **まちがえてもⒶ・Ⓑの記録は変わりません**。何度でも挑戦できる練習用です

## おぼえかたのしくみ(Ⓐ→Ⓑ 曜日別ボックス方式)

単語ごとに「何回連続で正解したか」を記録し、段階的に定着させる方式です。

- **Ⓐ たんごを れんしゅう**: 15語ずつの範囲を選んでフラッシュカード→4択クイズ。正解するたびその単語のカウントが+1され、画面にドット(●●●)で進捗表示
- **3回正解で Ⓑへ卒業**: カウントが3に達すると、その単語は**答えた日の曜日のボックス**(月〜日、7つ)に移動し、Ⓐの出題対象からは外れる
- **Ⓑ ようびボックス**: ホーム画面から曜日ごとのボックスを開いて復習できる。**今日の曜日のボックスがホームで通知**される
- **間違えるとⒶに逆戻り**: ボックス内で間違えるとカウントがリセットされ、Ⓐの学習プールに戻る。これにより「本当に覚えた単語だけ」がボックスに残り続ける

学習した曜日ごとに自然と復習が分散されるので、特定の日に復習が集中せず、毎週同じ曜日に思い出す機会が繰り返し訪れます。

## やる気が出る仕組み(マイクラ風)

- **🟩 ブロック / 🧰 チェスト**: 正解するとブロックが飛び散り、Ⓑへの卒業やボックス完全クリアでチェスト獲得
- **⬆️ 経験値バー**: 画面上部にマイクラそっくりのXPバー。貯まるとレベルアップ
- **🏆 進捗の達成**: マイクラの「進捗の達成」風トーストが卒業・レベルアップ時にポップアップ
- **🔥 コンボ**: 連続正解でコンボ表示
- **🔥 連続学習日数**: 毎日続けるほど伸びる
- **📕 まちがえた単語**: クイズ後にその場で見返せる

### 🎁 パックゲージ → パック開封(アイテム100種コレクション)

Ⓐのクイズ(15問)は**アイテムパックを賭けた挑戦**です。
画面の一番上に**パックゲージ**が出ていて、正解が増えるほどもらえるパックのレアリティが上がります。

```
              🎁
        いま レア パック
   ██████████ ▉ ▉ ░ ░ ░
        あと 2もん せいかいで エピック!
```

- マスは**右にいくほどレアリティが上がる**色で塗られていて、これから何を狙えるかが一目で分かります
- レアリティが変わるマスの上には区切りの印が付きます
- 間違えて届かなくなったマスは消えるので、「まだエピックは狙える」がはっきり分かります
- レアリティが1段上がった瞬間に「ランクアップ!」の演出が入ります

| 正答率(15問中) | レアリティ | 1パックの個数 | 収録数 | 開封演出 |
|---|---|---|---|---|
| 15問 (100%) | ⭐ レジェンダリー | 5個 | 12種 | 虹色の光線40本+全画面フラッシュ+紙吹雪110枚+画面揺れ+**PERFECT の帯**(ため2.6秒) |
| 14問 (90%〜) | 🟣 エピック | 3個 | 20種 | 紫の光線24本+フラッシュ+紙吹雪45枚+画面揺れ(ため1.9秒) |
| 12問 (80%〜) | 🔵 レア | 2個 | 28種 | 水色の光線14本+紙吹雪20枚(ため1.3秒) |
| 11問 (70%〜) | ⚪ コモン | 1個 | 40種 | 静かにパッと開く(ため0.8秒) |
| 10問以下 | — | パックなし | — | 「あと◯もん せいかいすると コモンパックが もらえるよ!」 |

- パックは**自分でタップして開ける**。タップすると音が段々と高くなり、レアリティが高いほど「ため」が長く、光と音が派手になります
- **まだ持っていないアイテムから先に出す**ので、図鑑が埋まりやすく同じものばかりで残念になりません
- アイテムは**マイクラのブロック・道具・モブ・ボス素材など全100種**。初めて手に入れたものには **NEW!** バッジ、被ったものには個数が付きます
- 開封の最後に**コレクションの埋まり具合(◯/100種)**が出ます

## 使い方

### GitHub Pages で公開する(おすすめ)

1. リポジトリの **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチをこのブランチ、フォルダを `/ (root)` にして Save
3. 発行されたURLをスマホ・タブレットのホーム画面に追加すると、アプリのように使えます

### ローカルで試す

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

学習の進み具合は端末のブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで続きから遊べます。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — マイクラ風ピクセルUI(角丸なし・ベベル・ドットフォント)
- `dialogue-data.js` — 大もん1・大もん2・リスニング第1部・第2部れんしゅう用のオリジナル会話文データ(99本)
- `words-data.js` — 単語データ(パス単順600語)、15語ずつのⒶ範囲、曜日ボックスの定義、SVG図解生成関数と抽象語の図解定義、ドロップアイテム100種(`DROP_TIERS`)、穴うめで出題する語(`TYPE_HARD_EN`)とそのまちがい選択肢(`CLOZE_DISTRACTORS`)、答えの言いかえ表(`JA_ALT`)
- `app.js` — 進捗管理・クイズ・Ⓐ→Ⓑ卒業ロジック・効果音・エフェクト・その日の記録(`P.today` / `P.history`)

## 単語を追加するとき

`words-data.js` の `WORD_LIST` に追記するだけで、15語ごとに自動でⒶ範囲が増えます。

```js
{ en: "book", ja: "ほん", emoji: "📕", ex: "I read a book.", exJa: "わたしは ほんを よみます。" },
```

絵にしにくい語には `VISUALS` に図解を足せます。絵文字の並びでよければ:

```js
people: { icons: ["👦","👧","👨","👩"], label: "たくさんの 人" },
```

もっとしっかり伝えたい場合は、専用のSVGを描いて `svg` フィールドに渡せます(`svgFreqMeter` `svgPrepBox` などが実例です):

```js
always: { svg: svgFreqMeter(4), label: "4こ ぜんぶ = いつも(100%)" },
```
