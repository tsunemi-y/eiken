# えいけんチャレンジ 5きゅう

小学生(小2)が **英検5級 (2026/10/4 実施)** に向けて単語を覚えるための、ゲーム感覚の単語学習アプリです。
サーバーもインストールも不要、ブラウザだけで動く1枚のWebアプリです。

## 特徴

- **単語網羅**: 英検5級レベルの単語 278語(数字・色・家族・体・動物・食べ物・学校・スポーツ・職業・場所・乗り物・天気・曜日/月・時間・形容詞・動詞・疑問詞・基本語)を収録し、10語ずつ「ゾーン」に分割
- **モチベーション設計**:
  - ⭐ スター(正解数に応じて累積) / 🎁 たからばこ(ゾーンクリア・復習合格ごとに獲得) / 🚩 レベル(クリアしたゾーン数)
  - 🥉🥈🥇 ゾーンごとのメダル(正答率に応じて銅・銀・金)
  - 🔥 連続学習日数、📈「じぶんの記録」画面で自己ベスト更新を可視化
  - クリア時の紙吹雪演出、すごろく風の「たんごマップ」
- **ゾーン制のレベルアップ**: 10単語=1ゾーン。フラッシュカードで覚えたら4択クイズ(10問)に挑戦し、80%以上正解でゾーンクリア→レベルアップ→宝箱ゲット→次のゾーンが解放
- **週次復習(スペースドリピティション)**: ゾーンをクリアすると7日後に自動で「復習テスト」対象になり、ホーム画面に通知。合格するとまた7日後に再スケジュールされ、定着を促す
- **試験日カウントダウン**: 2026/10/4までの残り日数と、残りゾーン数から逆算した「1週間に何ゾーン進めるべきか」の目安を自動表示
- **音声読み上げ**: Web Speech API でネイティブ発音を再生(🔊きく ボタン)
- 漢字にはふりがな(ルビ)、ひらがな中心のUIで小2でも一人で読める設計

## 遊び方

1. ホーム画面の「たんごを おぼえる」からスタート
2. フラッシュカードをタップすると意味と例文が表示される。🔊きく で発音確認
3. 10枚見終わったら「クイズに ちょうせん!」→ 4択クイズに10問挑戦
4. 8問以上正解でゾーンクリア!レベルアップ&たからばこゲット
5. 1週間後、そのゾーンが「ふくしゅうテスト」に登場するので復習する
6. 「たんごマップ」で全体の進み具合、「きろく」でスターやメダルを確認

## 使い方(公開・起動方法)

このリポジトリは静的ファイル(HTML/CSS/JS)のみで構成されているため、特別なビルドは不要です。

### ローカルで試す

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### GitHub Pages で公開する

1. GitHubリポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、ブランチをこのリポジトリのデフォルトブランチ、フォルダを `/ (root)` に設定
3. 発行されたURLをスマホ・タブレットのホーム画面に追加すると、アプリのように使えます

学習の進み具合(スター・宝箱・クリア状況など)は端末のブラウザの `localStorage` に保存されます。同じブラウザ・同じ端末で続きから遊べますが、別の端末やブラウザのシークレットモードでは引き継がれません。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — デザイン(子ども向けにカラフル・大きめのタップ領域)
- `words-data.js` — 単語データ(278語、10語ごとに自動でゾーン分割)
- `app.js` — 進捗管理・クイズロジック・復習スケジューリングなど

## 単語を追加・編集したいとき

`words-data.js` の `WORD_LIST` 配列にオブジェクトを追加するだけです。

```js
{ en: "book", ja: "ほん", emoji: "📖", ex: "I read a book.", exJa: "わたしは 本を よみます。" },
```

10個ごとに自動でゾーン番号が振られるため、並び順を変えるとゾーン構成も変わります。
