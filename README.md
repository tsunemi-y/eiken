# 📘 えいご 5きゅう

小2の子どもが **英検5級(2026/10/4)** に向けて練習するための、ブラウザだけで動く学習アプリです。
サーバーもインストールも不要。GitHub Pages に置いてスマホで開くだけで使えます。

## このアプリがやること

**最重要の155語を、「読んで」「聞いて」答えるだけ**のアプリです。

| | やること |
|---|---|
| 📖 **リーディング** | 英語を読んで、意味を4択でえらぶ |
| 🎧 **リスニング** | 英語を聞いて、意味を4択でえらぶ。**答えるまで英語の文字は出ません** |
| Ⓑ **ふくしゅう** | 覚えた語を曜日ごとのボックスで復習する |

リーディングとリスニングは**同じ155語・同じ範囲**を使い、問題の出しかたが違うだけです。
覚えた記録(3回正解でⒷへ)も共通です。

### 入れていないもの

本番が近づき、子どもが**文を読むところまで届いていない**ことが分かったため、
まず単語を「読んでわかる」「聞いてわかる」状態にすることに絞りました。

- **大もん1〜3・リスニング第1部/第2部の練習は外しました**。本番形式の会話文や
  並べかえは、単語が読めない段階では手が止まるだけだったためです
- **答えかたの切りかえ(こえで/4たく/かく)も外し、4択だけ**にしました
- ゲーム要素(アイテム・パック・XPなど)も入れていません。
  残っているのは正誤の表示と進捗バーだけです

見た目は**素の読みやすさ優先**です。英文は等幅のドットフォントをやめ、
読みやすいサンセリフ(Inter)で大きめに組んでいます。

### どう選んだか

5級はいちばん易しい級なので**ほぼ全部が頻出**で、どこを削っても何かは失います。
そのうえで次の方針で選びました。

- パス単は品詞・テーマごとに並んでいる(名詞→動詞→形容詞→機能語→数字→代名詞→熟語)ので、
  「前から◯語」で切ると**名詞だけが残って動詞が1つも入らない**。そのため分類ごとに選んでいる
- 文を読むのに欠かせない**代名詞・疑問詞・be動詞・基本動詞・前置詞**を優先
- 同じ語が2回載っているもの(`one` `you` `his` `her` `it`)は1つだけ
- 目的格(`him` `us` `them`)、所有代名詞(`mine` など)、4番目以降の序数、`a` `the` `of` は外した
- 名詞と形容詞は、学校・家族・食事・時間など5級の基本場面に出るものだけ

### 番号はパス単のまま・元に戻せる

**番号は配布プリントと同じ**です(範囲の見出しも「1〜45ばん」のようにプリントの番号)。
範囲は並び順のまま、ほぼ15語ずつ(16語×5・15語×5)に均等に分けています。

データ自体は消しておらず、`words-data.js` の `CORE_NOS` で絞っているだけなので、
番号を足せばすぐ戻せます。単語の `id` はパス単の番号そのものなので、絞っても
**保存済みの記録はずれません**。絞る前に覚えた語の記録も消さずに残してあり、
戻せばそのまま復活します(「おぼえた ◯/155ご」には範囲内の語だけを数えます)。

## Ⓐ→Ⓑ のしくみ(曜日別ボックス方式)

- **Ⓐ おぼえる**: 範囲を選んでカード→クイズ。正解するたびカウントが+1され、ドット(●●●)で表示
- **3回正解でⒷへ**: カウントが3に達すると、答えた日の**曜日のボックス**(月〜日)に移動し、Ⓐから外れる
- **Ⓑ ふくしゅう**: 曜日ごとのボックスを開いて復習。今日の曜日のボックスがホームで通知される
- **間違えるとⒶに逆戻り**: ボックス内で間違えるとカウントがリセットされⒶに戻る

学習した曜日ごとに復習が自然に分散されるので、特定の日に集中せず毎週思い出す機会が来ます。

## 📝 機能語は「文の穴うめ」で覚える

`at` `of` `is` `am` のような語は、**単語カードで1語だけ見せても覚えられません**。
「of = の」と暗記しても文の中で使えないからです。
そこで機能語は、単語の意味を問うのをやめて**文の穴うめで出題**します。
Ⓐの「おぼえるカード」にもこれらの語は**一切出しません**。

- **読み上げは空所を飛ばします**。答えの語まで読むと聞くだけで分かってしまうためです。
  空所の位置では代わりに短い合図音が鳴ります
- **リスニングでは文も隠します**。「I play (ポン) my friend.」を聞いて ( ) に入る語をえらび、
  答えたあとに文が出て空所が埋まります
- 対象は `TYPE_HARD_EN` のうち単語データに実在する語。
  例文データ側は全155語のうち**154語**で穴うめが作れることを確認済み
- ある範囲がすべてこの機能語だった場合は、カードを飛ばして直接クイズから始まります

### まちがい選択肢は1語ずつ手で選んである

ランダムに選ぶと「どちらでも文法的に正しい」問題ができてしまいます
(`I am ( ) school.` に `at` と `in` を並べると両方正解になる)。
そこで対象の語すべてについて、**絶対に入らない語**を3つずつ手で指定しています。

## 読み上げ(音声)について

Web Speech API を使い、端末に入っている読み上げエンジンで発音します。

- **英語**は覚える対象なのでゆっくり(rate 0.85)、**日本語訳**は意味の確認なので速め(1.35)
- 日本語は**端末内の声を優先**します。ネットワーク音声は喋る前に取りに行くぶん
  出だしが遅れ、英文のあとに間があいてしまうためです。英語は質を優先してネットワーク音声を使います
- 声の選択結果は `voiceURI` だけ覚えておき、使うときに今の一覧から引き直します
  (声のオブジェクトを持ち続けると、端末が一覧を作り直したときに無効になり無音になるため)
- 読み上げが壊れて `onend` が返ってこない端末でも、文字数から計算した保険タイマーで必ず進めます

**音が出ない場合**は端末側の読み上げエンジンが原因のことが多いです。
設定で「テキスト読み上げ」を検索し、Google テキスト読み上げが入っているか、
**英語の言語データがダウンロードされているか**を確認してください。

## 保存について

進捗は `localStorage`(キー `eigo_craft_v5`)に保存されます。端末を再起動しても消えません。
ただし**ブラウザの閲覧データ削除・シークレットタブ・別ブラウザ**では失われる/見えないので、
**いつも同じブラウザで開く**ようにしてください。

単語の `id` は配列の位置ではなく**パス単の番号そのもの**を使っています。
位置にすると単語を足し引きするたびに全部ずれて、保存済みの記録が別の単語に付いてしまうためです。
過去バージョン(v3: 600語 / v4: 420語)の記録は、起動時に番号を手がかりに自動で移行します。

## ファイル構成

- `index.html` — 画面の骨組み
- `style.css` — 見た目(読みやすさ優先のデザイン)
- `app.js` — 全ロジック
- `words-data.js` — 単語データ(パス単順。`CORE_NOS` で155語に絞り込み)、範囲、曜日ボックス、SVG図解、
  穴うめ対象語(`TYPE_HARD_EN`)とまちがい選択肢(`CLOZE_DISTRACTORS`)
